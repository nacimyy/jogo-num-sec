# 🎯 Jogo do Número Secreto

> Um jogo interativo onde você tenta adivinhar um número secreto com base em dicas de "maior" ou "menor".

---

## 📌 Sobre o projeto

O **Jogo do Número Secreto** é uma aplicação simples desenvolvida com JavaScript que desafia o usuário a descobrir um número aleatório dentro de um intervalo definido.

A cada tentativa, o sistema informa se o número digitado é maior ou menor que o número secreto, guiando o jogador até o acerto.

Este projeto foi desenvolvido com foco na prática de lógica de programação e manipulação de interação com o usuário.

---

## 🚀 Funcionalidades

- 🎮 Geração de número aleatório
- 🔢 Entrada de números pelo usuário
- 📉 Dicas de "maior" ou "menor"
- ✅ Mensagem de acerto com número de tentativas
- 🔄 Reinício do jogo
